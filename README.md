# Smart Urban Flooding & Drainage Management System

An AI-powered smart city solution designed to help urban authorities monitor,
predict, and manage flooding and drainage-related incidents.

## Key Features

- Flood risk assessment and mapping
- Drainage monitoring and management
- Real-time incident management
- Citizen flood reporting
- AI-powered assistant
- Flood damage assessment
- Civic response coordination
- Multi-agent AI workflow
- Interactive dashboard and demo scenario

## AI Agents

The system includes specialized agents for:

1. Flood Risk Assessment
2. Drainage Management
3. Civic Response
4. Citizen Reporting
5. Dashboard Management
6. Damage Assessment

## Technologies

- HTML, CSS, JavaScript
- Leaflet.js
- Chart.js
- Python
- FastAPI
- Pydantic
- IBM Cloud / IBM Granite (where configured)
